# **База данных строительных карнизов**

Консольное приложение для создания, хранения и управления информацией о строительных карнизах.

---

## 🎯 **Назначение**

Проект демонстрирует практическое применение структур данных, файлового ввода-вывода и алгоритмов поиска/сортировки в языке C. Предназначен для учета и управления данными о строительных карнизах с возможностью хранения характеристик и материалов.

**Образовательные цели:**
- Работа со структурами данных в C
- Реализация алгоритмов поиска и сортировки
- Файловый ввод-вывод
- Модульная архитектура программы

---

## 📋 **Функциональные возможности**

### **Основной функционал:**

- ✅ **CRUD-операции:** Создание, чтение, редактирование записей
- ✅ **Генерация данных:** Автоматическое заполнение случайными значениями
- ✅ **Поиск:** По фамилии, должности и зарплате
- ✅ **Сортировка:** По зарплате сотрудников
- ✅ **Загрузка:** Заполнение базы информацией из выбранного файла
- ✅ **Сохранение:** Текстовый формат для долговременного хранения
- ✅ **Консольный интерфейс:** Интерактивное меню с 8 командами

### **Структура данных карниза:**

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `firstName` | `char` | имя | Артём |
| `lastName` | `char` | фамилия | Когтин |
| `patronymic` | `char` | отчество | Эдуардович |
| `position` | `char` | должность | Программист |
| `salary` | `int` | зарплата | 46783 |
| `birthDate` | `char` | день рождения | 6.08.1987 |

## 🏗️ **Архитектура проекта**

### **Модульная структура:**
```
src/
├── lab19_20_21.c # Точка входа, управление меню
├── functions.h # Заголовочный файл с объявлениями
├── functions.c # Реализация всех функций
└── README.md # Документация
```

### **Ключевые алгоритмы:**

1. **Поиск:** Линейный поиск по массиву структур
   - По числовым полям: точное совпадение
   - По строковому полю: сравнение через `strcmp()`

2. **Сортировка:** сортировка пузырьком

3. **Генерация данных:**
   - Числа: равномерное распределение в заданном диапазоне
   - Строки: случайный выбор из предопределенного списка
  
4. **Загрузка/Сохранение**
  - Загрузка данных из выбранного файла
  - Сохранение данных в выбранный файл



### **Взаимодействие модулей:**
- `lab19_20_21.c` содержит главное меню и управление программой
- `functions.c` содержит операции с данными
- `functions.h` определяет интерфейс между модулями

## 🚀 **Сборка и запуск**

### **Требования:**
- Компилятор C (GCC/Clang/MSVC)
- Стандарт C99 или новее
- Операционная система: Windows/Linux/macOS

### **Инструкция по сборке:**

```bash
# 1. Клонирование репозитория (если есть)
git clone [URL-репозитория]
cd lab19_20_21

# 2. Компиляция всех файлов
gcc -std=c99 -o lab19_20_21.c functions.c

# 3. Запуск программы
./lab19_20_21      # Linux/macOS
lab19_20_21.exe    # Windows

```
